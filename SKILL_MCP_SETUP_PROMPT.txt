PROMPT (English, kisi bhi AI coding agent ke liye)
--------------------------------------------------------------------------------

Set up Skills + MCP + Agents GLOBALLY for Claude Code and OpenCode on this
Windows machine, using D:\ as the reference source. Follow these rules exactly:

1) LOCATIONS -- put things ONLY in the global/user scope so they work from
   every folder (C:\dev\*, C:\Users\Analysis, D:\, etc.):

   Claude Code:
     Global config dir : C:\Users\Analysis\.claude\
       agents\          -> one .md per agent, MUST start with --- and have
                            frontmatter:  name, description, tools, model
       skills\          -> one folder per skill, MUST contain SKILL.md
       hooks\           -> hook scripts (.py)
       settings.json    -> env, modelPicker, enabledPlugins, hooks
     MCP registry      : C:\Users\Analysis\.claude.json  -> "mcpServers": {...}
     Binary on PATH    : C:\Users\Analysis\.local\bin\claude.exe
                          (this folder must be in the USER PATH)

   OpenCode:
     Global config     : C:\Users\Analysis\.config\opencode\opencode.json
       "mcp"           -> { name: { type, command|url, enabled } }
       "provider"      -> LLM providers + apiKey
       "agent"         -> inline agent definitions
       "plugin"        -> plugin list
     Agents on disk    : C:\Users\Analysis\.config\opencode\agents\*.md
     Extra agent/skill kit : C:\Users\Analysis\.opencode\  (agents\, skills\,
                             commands\, plugins\, rules\, hooks\)

   Cross-tool Agent Skills (open format):
     C:\Users\Analysis\.agents\skills\<name>\SKILL.md

2) RULE -- a skill placed ONLY in  C:\Users\Analysis\.agents\skills  is NOT
   global for Claude Code. It only resolves when the current working directory
   itself contains a .agents\ folder. ALWAYS also copy every skill into
   C:\Users\Analysis\.claude\skills\  so it resolves from any folder.

3) PROJECT vs GLOBAL
     <project>\.claude\            overrides/extends  ~/.claude
     <project>\opencode.json       MERGES with the global opencode.json
                                    (it does NOT replace it)
   So keep shared agents/skills/MCP in GLOBAL. Keep only project-specific
   things (env, project-only agents) at project level.

4) MCP
   - Claude Code: add to  ~/.claude.json  ->  "mcpServers".
     Verify with:   claude mcp list        (expect: ... - Connected)
   - OpenCode:     add to  opencode.json  ->  "mcp", set "enabled": true.
     Verify with:   opencode mcp list
   - Local stdio servers on Windows need  ["cmd","/c","npx","-y","<pkg>"].

5) SKILLS format
   Each skill = a folder with SKILL.md:
     ---
     name: my-skill
     description: >-
       What it does and WHEN to use it.
     ---
     <instructions>
   Verify with:  claude -p "/my-skill reply with X"
   A skill that returns "not installed in this session" is in the WRONG folder.

6) AGENTS format (Claude Code)
     ---
     name: my-agent
     description: What it does / when to pick it
     tools: Read, Grep, Glob
     model: inherit
     ---
     <system prompt>
   Verify with:  claude -p --agent my-agent "reply with X"
   Broken/undecodable .md files are SILENTLY skipped -- always verify the
   available-agents list, do not trust the file count.

7) HEALTH CHECK (run from a folder with NO local config, e.g. C:\dev\graph-tools)
     claude mcp list
     claude -p --agent architect "reply with X"
     claude -p "/some-skill reply with X"
     opencode agent list
     opencode mcp list
     opencode run "reply with X"

8) THIS MACHINE'S EXTRA PREREQUISITE (NVIDIA, not optional)
   Claude Code is wired to a local proxy that translates the Anthropic API to
   NVIDIA.  ANTHROPIC_BASE_URL = http://localhost:4001
   If it is down, nothing works. Check and start:
       curl http://127.0.0.1:4001/health
       double-click  C:\Users\Analysis\.claude\start-nvidia-proxy.cmd
   Auto-start entry:  Startup\nvidia-proxy.lnk
   Log:  C:\Users\Analysis\.claude\nvidia-proxy.log

--- Claude Code ---------------------------------------------------------------
  claude                                        # interactive TUI
  claude -p "prompt"                            # one-shot, output on stdout
  claude mcp list                               # MCP health
  claude -p --agent <name> "prompt"             # run a specific agent
  claude -p "/<skill> prompt"                   # invoke a skill
  claude agents                                 # interactive agent browser (TTY)
  claude --help                                 # all flags

  Careful: --allowedTools is VARIADIC. Keep the prompt right after -p:
    claude -p "do X" --allowedTools "Bash"      <-- correct
    claude -p --allowedTools "Bash" "do X"      <-- WRONG (prompt eaten)

--- OpenCode ------------------------------------------------------------------
  opencode                                      # interactive TUI
  opencode run "prompt"                         # one-shot
  opencode mcp list                             # MCP health (aliases: ls)
  opencode agent list                           # all agents
  opencode models [provider]                    # models of a provider
  opencode agent create                         # new agent
