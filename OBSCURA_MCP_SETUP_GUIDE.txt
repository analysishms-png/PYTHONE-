1. WHAT THIS IS
--------------------------------------------------------------------------------
Obscura is a headless browser engine written in Rust (~76 MiB, no Chromium,
no Node, no other dependencies). It ships an MCP server that exposes browser
automation tools to AI agents. This machine runs it as a GLOBAL OpenCode MCP
server named `obscura-browser`.

  Repo        https://github.com/h4ckf0r0day/obscura

  Changelog   https://github.com/h4ckf0r0day/obscura/releases/tag/v0.2.5

4. MCP CONFIGURATION (the exact block)
--------------------------------------------------------------------------------
    "mcp": {
      "obscura-browser": {
        "type": "local",
        "command": [
          "C:\\Users\\Analysis\\.local\\obscura\\obscura.exe",
          "mcp"
        ],
        "enabled": true,
        "timeout": 120000
      },
      ...
    }

Notes:
  - OpenCode's key is `mcp` (NOT `mcpServers`).
  - `type` and `command` are REQUIRED by the schema (McpLocalConfig).
  - stdio transport is the default of `obscura mcp` (we do NOT pass --http,
    which would open a network port instead).
  - Absolute paths - works regardless of cwd.
  - NO API key / credential is used or stored.
  - `timeout: 120000` matches the other local entries in this file
    (default is only 30 s, too tight for slow page loads).
  - Server name `obscura-browser` becomes the tool prefix, so tools appear
    as `obscura-browser_browser_navigate`, `obscura-browser_browser_click`, ...

State after install:  15 MCP servers total, 6 enabled:

6. USAGE EXAMPLES
--------------------------------------------------------------------------------
In an OpenCode prompt, name the server to steer the agent:

  "Use obscura-browser to open https://example.com and tell me the page title."

  "Use obscura-browser to fill the search box on https://example.com
   and take a snapshot of the results."

  "Use obscura-browser to screenshot https://news.ycombinator.com"

CLI smoke test (no OpenCode needed):
    obscura.exe fetch https://example.com --eval "document.title"
    obscura.exe fetch https://example.com --dump text
    obscura.exe fetch https://example.com --screenshot page.png

Localhost / LAN dev servers are BLOCKED by default (SSRF protection).
Allow them explicitly:
    obscura.exe --allow-private-network fetch http://127.0.0.1:3000 --dump text
  (or set OBSCURA_ALLOW_PRIVATE_NETWORK=1)

8. TROUBLESHOOTING
--------------------------------------------------------------------------------
"obscura-browser" not in `opencode mcp list`
  -> Check the entry exists in the GLOBAL file (not a project opencode.json):
       C:\Users\Analysis\.config\opencode\opencode.json
  -> Check the exe path in `command` exists.

MCP spawns but tools are missing / timeout errors
  -> Raise "timeout" in the entry (ms). Page loads on slow networks need it.
  -> Run `node _probe.mjs` to see whether the server itself answers.

`spawn ...obscura.exe ENOENT`
  -> PATH entry missing, or the absolute path in `command` is wrong.
     Check:  [Environment]::GetEnvironmentVariable('Path','User')

Screenshot produced no file
  -> Expected. `browser_screenshot` takes ONLY width/height and returns the PNG
     as an inline MCP image. There is no `path` argument.

Cannot reach http://localhost:... or a LAN host
  -> Obscura blocks private IPs by default. Use --allow-private-network or
     OBSCURA_ALLOW_PRIVATE_NETWORK=1 (see docs/Environment-variables.md).

Tool names look like `obscura-browser_browser_navigate`
  -> Normal. OpenCode prefixes MCP tools with the server name.
     To disable them all at once use a glob in config:
       "tools": { "obscura-browser_*": false }

Want to turn it off without deleting it
  -> In the global opencode.json set:  "enabled": false

Other MCP servers became slow
  -> MCP tools all count against context. Disable servers you do not use:
       "tools": { "serverName_*": false }
     or set that server's "enabled": false.

11. SECURITY NOTES
--------------------------------------------------------------------------------
- Third-party binary. Tag is GPG-verified, but this project publishes NO
  SHA256 checksum assets, so supply-chain verification is limited to GitHub's
  signature on the release tag.
- Obscura runs with YOUR privileges: full local file + network access.
  Treat it like any other local tool you trust.
- No API key or credential is stored for this server.
- MCP server binds nothing by default: stdio only. The `--http` mode (which
  would listen on 127.0.0.1:3000) is NOT used here - do not expose it publicly.
- Private/internal IPs are blocked by default (SSRF guard). Do not disable
  --allow-private-network unless you trust the target.
- Agent policy for this machine: ask before logging into real accounts,
  before submitting sensitive forms, and never do irreversible actions
  without explicit approval. (Verification run filled a practice form at
  quotes.toscrape.com but deliberately did NOT submit it.)
